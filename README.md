# RimeVision

Rime 输入法可视化配置工具，当前重点维护跨平台版 WeaselVision。

## 版本状态

### 0.3.0

0.3.0 在 0.2.0 的基础上进行了大量后端重构和 UI 优化，进一步完善了主题、方案、通用设置、按键绑定、标点、备份、同步和部署等核心功能。

作为 Rime 的可视化配置工具，当前功能已经趋于完善和稳定。后续不会再进行大量新功能开发，维护重心将转向长期使用积累后的 bug 修复、兼容性修正和必要的小幅体验优化。

## 功能

- 🎨 **主题编辑器** — 可视化编辑 Rime 配色方案和样式
- 📋 **方案管理** — 管理输入法方案及其依赖关系
- ⌨️ **快捷键编辑** — 配置按键绑定
- ⚙️ **通用设置** — 标点符号、候选词等全局选项
- 💾 **配置管理** — YAML 配置文件的导入、导出和备份
- 🚀 **一键部署** — 将配置部署到 Rime 输入法

## 技术栈

- **前端**: Vue 3 + TypeScript + Vite
- **桌面端**: Tauri 2
- **后端**: Rust
- **配置格式**: YAML

## 构建 & 运行

```bash
cd weasel_vision
npm install
npm run tauri dev
```

构建前端:

```bash
npm run build
```
